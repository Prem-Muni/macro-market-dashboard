Reading the dashboard responsibly

Specialized index breadth data may require separate authorized data sources. An incomplete 15-point score can be a range, not a definitive RISK-ON / CAUTION / RISK-OFF classification.

The website uses the original Thinkorswim-style 50D/200D trend point plus a separate RSI(14) point in an experimental 15-point model. The original 14-point score remains visible for comparison. Five individual SMA comparisons are informational only. Thinkorswim itself is not updated by this package. It is not a broker feed, a backtested strategy, or an instruction to trade. Futures and ETF proxies can differ from Thinkorswim settlements. Provider availability and data display rights vary.
