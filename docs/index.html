Reading the Dashboard Responsibly

Specialized index breadth data may require separate authorized data sources. An incomplete 16-point score can be a range, not a definitive RISK-ON / NEUTRAL / RISK-OFF classification.

The website uses the original Thinkorswim-style 50D/200D trend point plus a separate RSI(14) and MACD(12,26,9) points in an experimental 16-point model. The original 14-point score remains available as an inverted health reference. Five individual SMA comparisons are informational only. Install the accompanying Thinkorswim health-score study separately. It is not a broker feed, a backtested strategy, or an instruction to trade. Futures and ETF proxies can differ from Thinkorswim settlements. Provider availability and data display rights vary.
