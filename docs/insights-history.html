How to use this archive

Each dated row captures SPY or QQQ's completed close, day-over-day ETF price change, daily bearish score, daily change in bearish points, risk regime, 5-day trend, data coverage and matching price/risk alert. Select Signals to inspect the same-session changes available in the engine's snapshot.

Scores use the website's experimental 15-point model; Thinkorswim remains a separate 14-point reference. Constituent-derived breadth may be estimated, and observations are not proof of predictive accuracy. Archive persistence: data is stored in docs/data/latest.json and included in the existing GitHub Actions snapshot commit. Download a CSV periodically for a personal backup.
